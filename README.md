# Chica-Go! CTA L Scavenger Hunt / City Explorer Game

![CTA L Official Logo](https://www.transitchicago.com/assets/1/6/pageheader_ctatrademarks.png)

Explore and experience many great things of Chicago one CTA L station at a time.

## Tech Stack
- **Frontend:** React
- **Backend:** Java (Spring Boot)
- **Database:** SQLite
- **ETL:** Python/SQL
- **API:** Google Maps
- **Data Source:** Overpass OpenStreet
